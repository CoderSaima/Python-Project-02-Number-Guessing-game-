# Python-Project-02(Number-Guessing-game)
This is the simple number guessing game in python, that help the user to guess the correct number by giving him some hints.
e.g. if the user input number is larger than the selected one the system will ask for enter smaller number than existed input and if the user input number is smaller than the selected one the system will ask for enter larger number than existed input. The system also returns the attemptations in which the user guess the number.
